# Security policy

## Reporting a vulnerability

If you believe you have found a security or privacy issue in kernR, please report it privately rather than opening a public GitHub issue.

**Email**: max.moldovan@gmail.com
**Subject prefix**: `[kernR security]`

Please include:

- The version of kernR (`packageVersion("kernR")`).
- A minimal reproducible example demonstrating the issue.
- Your assessment of severity and impact, where possible.

You can expect:

- An acknowledgement within seven days.
- A coordinated-disclosure plan if the report is confirmed: a private fix branch, a CVE if appropriate, and a public advisory + patched release.

Please do not perform tests against systems you do not own.

## Supported versions

kernR is currently in early development; only the latest release on `main` is supported with security fixes. Once the package reaches stable status, this section will be updated with a versioned support matrix.
